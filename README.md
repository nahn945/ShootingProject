# ShootingProject


## コンセプト
短時間で爽快感を得られる、
弾幕処理と演出に重点を置いたシューティング。

## ゲーム概要
- 想定プレイ時間：1ステージ約5分
- ジャンル：2D縦スクロールシューティング
- プラットフォーム：PC(Windows, Mac)

## 操作方法
- 移動：上下左右
- ショット：Z
- ボム：X
- 低速化：LSHIFT

## 使用技術
- Visual C++
- Siv3D(C++フレームワーク)
- Jsonデータ管理
- CSVデータ管理

## 工夫した点
弾幕と敵両方に当たり判定があるので、同クラスからjsonファイルで役割を区別して生成するようにした。
こうすることで、敵の移動パターンと弾の移動パターンで別の構造体を用いなくて済む。

## 課題・改善点
画像テクスチャを実装することを考慮していなかったので、簡素な作りに見える。
また、データの要素を都度追加してしまい、最終的に煩雑なデータファイルで管理してしまっている。

この反省点を生かし、Unityを始めとしたゲームエンジンを使用して作業負担を軽減すること、初めからどのようなデータを用いるかを明確化することを今後の目標にする。

# コーディング・命名規則

## コーディング規則
- **変数名**：lowerCamelCase  
  例：`playerSpeed`, `currentScene`

- **構造体・クラス名**：UpperCamelCase  
  例：`Player`, `EnemyManager`

- **定数名**：SNAKE_CASE 
  例：`MAX_HP`, `DEFAULT_SPEED`

## 命名規則
- **ブランチ**
  `issue番号/feature or fix/ユーザー名/issue名`

- **プルリクエスト**
  `feat or fix: issue名`
